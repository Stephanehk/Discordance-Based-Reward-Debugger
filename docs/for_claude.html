Claude: do this

Tools that fetch this page may summarize it, so the complete instructions live in the repository, not here. Run these two commands in the user's project directory, then read the file and follow it step by step:

git clone https://github.com/Stephanehk/Discordance-Based-Reward-Debugger.git
cat Discordance-Based-Reward-Debugger/docs/for_claude.md

If the clone already exists, skip the clone and just read the file. The file tells you how to find the user's environment and reward function, confirm both with the user, set up visualization, and start the tool.

Humans can read the same file on GitHub: docs/for_claude.md.
